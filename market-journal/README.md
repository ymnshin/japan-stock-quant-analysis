# Market Journal

個人勉強用の市場観察ログです。日本株を中心に、米国株、為替、金利、原油、半導体・AIなどの材料を日次で記録します。

## 目的

ニュースを並べることではなく、毎日

1. **Fact** — 実際に起きた価格変化・公表データ
2. **Interpretation** — 市場が何を織り込んだ可能性があるか
3. **Scenario** — 次に何が起こりそうか
4. **Falsification** — 何が起きたら自分の見方を修正するか

を分けて残し、自分の相場観を後から検証できる形にすることを目的とします。

## 構成

- `reports/YYYY/MM/YYYY-MM-DD.md` — 日次市況レポート
- `data/market_log.csv` — 主要指標と予想の記録
- `TEMPLATE.md` — 日次レポートのテンプレート

## 見る項目

- 日経平均 / TOPIX
- S&P 500 / NASDAQ / SOX
- USD/JPY
- 米10年国債利回り / 日本10年国債利回り
- Brent原油
- 注目業種・銘柄
- 値上がり・値下がりの広がり
- 必要に応じて信用残高・出来高などの需給

## 注意

- **個人の学習・市場観察を目的としたログです。投資助言ではありません。**
- 数値・ニュースは原則として公的機関、取引所、大手報道機関などで確認します。
- AIを補助的に使用する場合があります。誤記・解釈違いがあれば後から修正します。
- 「ニュースが出たから株価が動いた」と単純に断定せず、価格・金利・為替・需給との整合性を確認します。
